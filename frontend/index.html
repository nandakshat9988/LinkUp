Simple Workflow

How LinkUp Works

From posting a match to stepping onto the field in 3 easy steps.

1

Post or Discover

Create an activity with your venue, scheduled time, and player capacity, or browse nearby open games.

2

Request to Join

Click on any activity to open its dedicated details page, view requirements, and send a join request.

3

Host Confirms & Connect

The host confirms incoming join requests. Once confirmed, contact details are revealed and the match completes!

Modern Architecture

Clean, Resilient Engineering

Engineered with Express.js, MongoDB Atlas, Redis rate limiting, and Python ML.

🔒

Stateless JWT Auth

Secure authentication with salted bcrypt passwords and signed JWT tokens carrying user identity across API endpoints.

🛡️

Location Rate Limiting

Guards location-sensitive proximity endpoints against scraping attacks with Redis store and in-memory fallback.

☁️

Unified Web Service

Express serves both the robust REST API routes and the client UI on a single dynamic port with zero CORS friction.
